> {{ site.Data.seo.description }}

module: hugolify-theme-bootstrap (Bootstrap 5, the default) or
hugolify-theme-design-system (framework-free, preview). In v1, Bootstrap CSS and JS
were bundled inside hugolify-theme.

This file inlines every documentation and tutorial page as plain text.
The v1 documentation is archived at https://v1.hugolify.io/
