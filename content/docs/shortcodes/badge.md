---
title: Badge
description: Displays a badge with different state in your body markdown.
icon: badge-check
---

## Example

### Markdown usage

```go-html-template
{{</* badge text="Lorem ipsum" state="warning" */>}}
```

### HTML rendered

```html
<span class="badge badge-warning">Lorem</span>
```

### Visual renderer

{{< badge text="Lorem ipsum" state="warning" >}}

## Datas

```yaml
text: "" # string
state:
  [
    "danger",
    "dark",
    "info",
    "light",
    "primary",
    "secondary",
    "success",
    "warning",
  ] # select
```
